Seus dados ficam salvos neste navegador. Configure a sincronização para acessá-los em outros dispositivos.

Sincronização entre dispositivos

Configure seu app Web do Firebase para ativar o acesso pela nuvem.

Configuração pública do Firebase

No Firebase Console, abra Configurações do projeto → Seus apps → Web. Essas informações públicas identificam o app; nunca informe chaves privadas de serviço.

Regras necessárias do Firestore

No Firebase Console, ative Authentication por e-mail/senha, crie o banco Firestore e publique regras que permitam cada usuário acessar apenas seus próprios dados:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/pfo/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}

Adicione realdevboy.github.io aos domínios autorizados do Firebase Authentication. Faça backup antes de conectar um dispositivo com dados existentes.
